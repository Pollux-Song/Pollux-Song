# Pollux-Song

嵌入式软件方向实习生，专注于端侧数据采集、断网续传和边缘计算。

## 项目

### emb-gateway
端云一体数据采集系统（MVP）
- C + Linux，环形缓冲 + CRC8 帧编码 + MQTT 发布
- 断网自动缓存，恢复后按序补传，丢包率 0
- 云侧 Python 订阅落库，提供 HTTP 查询接口

### c-labs
C 语言底层实验合集
- 指针与内存模型、位运算、volatile/static/const 语义
- 结构体对齐、字节序、编译链接错误排查

## 技能
- C（嵌入式方向）、Linux 系统编程、MQTT
- 环形缓冲区、CRC 校验、协议设计
- Python（云侧订阅、数据处理）
